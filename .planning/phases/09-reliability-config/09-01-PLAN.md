  <files>electron/main.js, electron/js/state.js, python/server.py</files>

  <action>
Three changes to eliminate hardcoded port 5199 from active code paths:

1. **electron/main.js line 7** — Replace `const PORT = 5199` with:
   ```javascript
   const PORT = parseInt(process.env.PORT || '5199', 10)
   ```
   Everything downstream (spawn env injection on line 60, waitForBackend, ipcMain get-port handler) already references this `PORT` constant, so no other changes needed in main.js.

2. **electron/js/state.js line 6** — Change `port: 5199` to `port: null` in the S object:
   ```javascript
   const S = {
     step: 1, done: new Set(), port: null,
     // ... rest unchanged
   ```
   The runtime value is already set by `window.S.port = await window.api.getPort()` in the index.js init() function, so null is just the pre-init placeholder.

3. **python/server.py** — Add a module-level `_ALLOWED_ORIGIN` constant after imports (after line 10, before `app = Flask(__name__)`):
   ```python
   _PORT = int(os.environ.get("PORT", PORT))
   _ALLOWED_ORIGIN = f"http://127.0.0.1:{_PORT}"
   ```
   Then replace the three hardcoded `5199` strings in the `cors()` function (lines 98-101):
   - Line 98: `"http://127.0.0.1:5199"` becomes `_ALLOWED_ORIGIN`
   - Line 99: `"http://127.0.0.1:5199"` becomes `_ALLOWED_ORIGIN`
   - Line 101: `"http://127.0.0.1:5199"` becomes `_ALLOWED_ORIGIN`

   The resulting cors() function:
   ```python
   @app.after_request
   def cors(r):
       origin = request.headers.get("Origin", "")
       if origin in (_ALLOWED_ORIGIN, "null", "") or origin.startswith("file://"):
           r.headers["Access-Control-Allow-Origin"] = origin if origin else _ALLOWED_ORIGIN
       else:
           r.headers["Access-Control-Allow-Origin"] = _ALLOWED_ORIGIN
       r.headers["Access-Control-Allow-Headers"] = "Content-Type"
       r.headers["Access-Control-Allow-Methods"] = "GET,POST,OPTIONS"
       return r
   ```

Do NOT change `python/constants.py` — `PORT = 5199` there is the default fallback, not an active hardcoded reference.
